# Seen action families by object class — reviewed source for lib/text/data/actFamilies.json
# (built by scripts/text/build-act-families.mjs, read by lib/text/sameAct.js).
#
# Written by hand from (verb, head-object) pairs mined from the duty lines of 959 real job postings and the résumé
# fixtures (scripts in the session scratchpad; one third of the mined pairs was set aside unseen before this file was
# written, to measure it). A verb means the same act only for the KIND OF THING it acts on: "run" a store is "manage"
# a store; "run" tests is not. So every family belongs to one object class.
#
# Format
#   @class id: noun, noun, …          the object class and the head nouns that put an object in it (singular, lower case;
#                                     multi-word allowed). A noun may sit in several classes ("equipment" is operated,
#                                     checked and cleaned); the verb picks the reading.
#   @class id [broad]: …               a BROAD class (systems, projects, documents): the same act on two different things
#                                     in it is only a guess ("implement audits" vs "implement integrations"); in a
#                                     narrow class it is close ("train cashiers" vs "train new hires").
#   family id: verb, verb ; near: verb, verb
#                                     verbs before "near:" are the SAME ACT on this class (interchangeable on a résumé);
#                                     "near" members are related, never proof (a tie-break). Verbs are base forms;
#                                     multi-word verbs allowed ("ring up", "put away").
#   edges: a => b, c => d             ONE-WAY: a résumé that says a shows a posting's b; b does not show a
#                                     (coach => train: coaching is training; training is not coaching). Edges may join
#                                     families of the same class.
#
# Families with fewer than 3 instances in the (two-thirds) mined pairs are kept below as comments, not shipped.
#
#   @link class.family ~ class.family   two families of different classes that are related acts (both ways): a
#                                     match across them is a guess, never proof, and never "different object class"
#
# Two verbs in DIFFERENT families of the same class are different acts ("track sales goals" does not show "exceed
# sales goals"; "follow procedures" does not show "write procedures").
