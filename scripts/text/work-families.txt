# Seen work thesaurus — reviewed source for lib/text/data/workFamilies.json (built by scripts/text/build-work-families.mjs).
# Written by hand as a lexicographer of workplace English, from the most frequent verbs and nouns of O*NET 31.0 task
# statements (USDOL/ETA, CC BY 4.0) and 682 real job postings; WordNet 3.1 consulted for candidates. A family holds words
# that mean the same work act / thing ON A RÉSUMÉ, interchangeably. Not a family: near neighbours that differ in level,
# scope or field (supervise ≠ assist; sales ≠ marketing; nurse ≠ doctor).
#
# Words that NAME an industry or a department (sales, insurance, finance, security, operations, support, marketing)
# are fields, not objects: they are never family members, so "B2B sales" and "insurance policy" cannot match by them.
#
# Format
#   @actions / @objects                      section
#   id [field,field]: member, member, …       one family; [fields] optional (objects only): the fields where it holds
#   member?objA|objB                          conditional member: counts only when the object it acts on (or the
#                                             other phrase's object) is one of those words, or in the object family of
#                                             one of them, or in a family with that id
#   multi-word members are phrases ("work with", "look-ahead"); every member is lower case, base form.
