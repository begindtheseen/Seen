# Seen trade-talk table — reviewed source for lib/text/data/tradeTalk.json (built by scripts/text/build-trade-talk.mjs).
# Written by hand from the trades' own usage, O*NET 31.0 task and tool text (USDOL/ETA, CC BY 4.0) and the wording of
# real postings. Each line is one group, valid ONLY inside its field (outside it, the API answers null):
#
#   @field food,retail            the fields the following groups hold in (several allowed)
#   = a, b, c                     equivalents: abbreviation ⇄ long form, trade word ⇄ plain words (either direction)
#   > instance, instance => class, class      one way: an instance shows its class ("ServSafe" shows "food safety
#                                             certification"); the class never shows the instance
#
# Members are lower case; matching ignores punctuation, plural / past endings and letter case. Left out on purpose:
# terms whose meaning flips by employer, and pairs that are near but not the same (CPR vs BLS; pallet jack vs forklift).
