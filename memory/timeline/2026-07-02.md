## Verified (ground truth still cited by knowledge notes)
- `applications` prod schema: `events jsonb`, `job_id` **text** (not uuid),
  `applied_at` exists.
- Credits gate lives at `lib/server/credits.js` (NOT `api/_utils/credits.js` —
  that path was a stale note that later sessions had built on).
- Vercel crons fire as **GET** (`x-vercel-cron` header) — cron handlers must
  route GET into refresh logic.
- Stripe: `api/stripe.js` disables the body parser and reads the raw stream
  (webhook HMAC needs exact bytes); subscription reads must NOT use
  `expand[]=items` (invalid — 502'd subscription management).
- Company slug scheme is ONE everywhere:
  `encodeURIComponent(name.toLowerCase().replace(/\s+/g,'-'))`.
