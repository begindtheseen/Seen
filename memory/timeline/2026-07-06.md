## Shipped — session 2: Temporal memory (Chronos)
Upgraded the flat vault into a **bi-temporal** system — the leap past a plain
Obsidian vault (motivated by the "Ken" temporal-memory video). Full design:
[[temporal|Chronos]].
- **One authority, derived graph.** Vault stays the single source of truth; a
  fact graph is *derived* from it (`scripts/memory-sync.mjs` → `memory/.graph/`),
  never edited directly. Rejected the common bidirectional Obsidian↔graph
  "circle" that creates two sources of truth. Logged in [[decisions/log]].
- **Typed bi-temporal facts** added to note frontmatter (`facts:`), each with
  valid-time (`valid_from`/`valid_to`) + transaction-time (`recorded`/
  `invalidated`) + `source` + `confidence`. Supersede-never-overwrite.
- **Engine:** `lib/server/memoryGraph.js` (pure, 13 tests in
  `memoryGraph.test.mjs`) — point-in-time search, what-changed delta,
  contradiction detection, timeline, entity lookup.
- **Local MCP server** `memory/mcp/server.mjs` (dependency-free stdio) exposes
  `memory_search_facts`, `memory_whats_changed`, `memory_contradictions`,
  `memory_timeline`, `memory_get_entity` to Claude. Wiring: [[mcp/README]].
- **Graphiti-ready:** same derived episodes/facts are the exact payloads a
  self-hosted Graphiti+FalkorDB engine ingests later — runbook + docker-compose
  in [[graph/README]] (owner's GCP steps; not required for temporal memory today).
- npm scripts: `memory:sync`, `memory:check`, `memory:mcp`.

**Proof it works:** `memory_search_facts({subject:"Seen free tier", as_of:
"2026-07-01"})` → **3** daily credits; same query today → **1**. The superseded
3/day fact is preserved with its closed validity window, not deleted.
