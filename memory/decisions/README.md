# Decisions

Locked owner/engineering decisions that must not be relitigated. The single
running record is [[decisions/log]]. Add to it at session end whenever the owner
locks a call (pricing, policy, infra, architecture) — see [[protocol]].

Why a dedicated log: Seen has repeatedly burned effort building before a business
decision was settled (the trial was built/patched/rebuilt/deleted in one day).
Rule 6 — "decide once, build once" ([[architecture]]) — depends on decisions
being written down where the next session will see them.
